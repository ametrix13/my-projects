## Featured Project

### Monster District Online

A browser-based action game prototype built with vanilla JavaScript and the HTML5 Canvas API.

Key features:

- Real-time multiplayer player synchronization
- MQTT over secure WebSockets
- Multiple playable forms and abilities
- Combat, health and energy systems
- Wanted level and bounty mechanics
- Hero / criminal reputation progression
- Local save system with `localStorage`
- Remote-player interpolation for smoother movement
